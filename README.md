# Supply Chain Digital Portfolio
# 供应链数字化作品集

Personal portfolio focused on supply chain analytics, exception management and material planning.

个人供应链数字化作品集，主要展示供应链异常管理、数据分析、BOM 齐套分析及供需情景规划能力。

All projects use public or synthetic data. No company-sensitive information is included.

所有项目均使用公开或模拟数据，不包含任何实习公司的真实敏感数据。

## 01 · Supply Chain Analytics & Exception Management
## 供应链运营分析与异常管理

A supply-chain analytics application covering inventory, orders, suppliers and exception prioritization.

基于订单、库存、采购及供应商数据搭建的供应链异常管理工具，用于识别并排序需要优先处理的业务异常。

**Key features / 核心功能**

- PostgreSQL relational data model
- SQL business views
- FastAPI backend
- Interactive web dashboard
- Exception drill-down
- CSV export
- Text-to-SQL query

## 02 · Multi-Level BOM CTB & Scenario Planning
## 多层 BOM 齐套分析与供需情景规划

A material-planning application for multi-level BOM explosion, weekly CTB analysis, shortage tracing and what-if scenarios.

基于多层 BOM、需求、库存及未来供应进行周度齐套分析，并支持缺料追溯及供需情景模拟。

**Key features / 核心功能**

- Multi-level BOM explosion
- Weekly CTB calculation
- Shortage detection
- Where-used tracing
- BOM editor and validation
- Supply scenario planning
- PostgreSQL scenario persistence
